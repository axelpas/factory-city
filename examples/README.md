# Examples

Two pages that open offline, one file each. Open them in a browser; nothing is fetched.

| File | What it shows |
|---|---|
| `factory-city.html` | This repository, one frame per issue. `factory-city.mp4` is the same timelapse as a film. |
| `twenty-ui.html` | A module of a public project, from the first issue to the last of its history. |

Both are written by `pnpm docs:assets`.

## About `twenty-ui.html`

- **Source:** the `packages/twenty-ui` module of [twentyhq/twenty](https://github.com/twentyhq/twenty), pinned to the tag `twenty/v2.58.0`. The files under `src/icon` are left out.
- **License:** the module is MIT-licensed, as the rest of that repository. This page holds paths and metrics only, no source code.
- **Redacted:** it was written with `--redact`. It carries no commit subject, issue title, author or agent label, fact, cost or declaration name, so no contributor of that project is named in it.
- **Not affiliated:** Factory City is not affiliated with Twenty.
